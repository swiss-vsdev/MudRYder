# MudRYder
The best game ever created

By Aurélien Santi and Gabriel Zeizer extends coffee-s

### Goal
The goal is to recreate a game similar to "Line Rider" fully in scala

## Dependencies
- Scala 2.13.18
- Java 25
- gdx2D
